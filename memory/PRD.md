# BEARFRAME: GHOST SIGNAL — PRD
## Problem statement
Playable HTML5 2D top-down sci-fi mystery/survival-horror mission (Mission 01: The Silent Facility) in the Bearframe universe, protagonist Wraith (WTR-07, Watchtower). Proposed future side story; lore must stay canon-safe (facility origin unresolved; trace is an anomaly, not a person; drone non-sentient).
## User choices
Drone contact drains energy (cooldown), zero energy restores checkpoint; scan disables drone at energy cost; generated WebAudio sound; D-pad left / actions right.
## Architecture
Static, dependency-free. /app/frontend (serve.js static server, `yarn start`), game in /app/frontend/public:
- js/main.js boot/menus/loop; js/game.js engine (collision, drone AI+BFS, ghost trace, lighting, scan, checkpoints)
- js/missions/{index,mission1}.js mission data+script (add missions here); js/art/{wraith,tiles}.js procedural pixel art
- js/engine/{input,audio,save}.js; js/ui.js; css/game.css. Saves: localStorage. No backend/DB used.

## Bearframe Sprite Studio (June 2026, tested iteration_4)
- Standalone tool at /studio/ (frontend/public/studio), no game imports. lib/: sprite-rig.js (humanoid), machine-rig.js (generic part/joint rasteriser: plate, taper, disc, ring, cable, banner, glass; motion channels), machine-presets.js (Heavy Sentinel, Hexapod, Archive Sentinel, Micro-drone, blank), sprite-sheet.js (project v2 with exploration + battle sets, import/export, zip).
- Editor: pixel tools, onion, guides, pivots, frame strip, anim props, rig part/motion JSON editing, reference tracing + colour pick, PNG sheet import, PNG+JSON export, frames ZIP, .bfsprite.json save/open, autosave.
- examples/*.bfsprite.json regenerated by `node studio/tools/make-examples.mjs` (from frontend/public).
- Limits: no image-to-sprite generation, no drag-bone UI, no generated turn anims; example machines are rough validation rigs, not finished art. Ghost Signal still uses its own js/art/wraith.js (not yet switched to studio exports).
