4. WHAT WAS JUST REBUILT AND IS DEFINITELY SAVED

Added in merged PR #5:
frontend/public/js/engine/campaign-narrative.js

frontend/tests/browser-campaign-narrative.mjs

Updated:
docs/PRIVATE_NARRATIVE_RUNTIME.md

This is a live dialogue/choice adapter around the saved pure narrative runtime.
It uses the original Ghost Signal UI without modifying the locked ui.js.

Current API:

mountCampaignNarrative({
  game, ui, content,
  readWorld, commitWorld,
  choiceGates,
  canComplete,
  onComplete,
  onBlocked,
  choiceRoot
})

Returns:
- trigger(actualTrigger, {sceneId} = {})
- resume()
- inspect()
- stop()

readWorld returns the current world record.
commitWorld(nextWorld) is SYNCHRONOUS and must return exactly true only after
a durable successful write. Promise-based saves are not this adapter's contract.

Progress lives in world.narrative. Narrative flags merge into world.flags.
Unrelated inventory and other world fields are preserved.

Choice staging is explicit:
choiceGates[choiceId] = {afterLine: lineId}
or {afterLine: null} for a choice before the first line.
Missing/unreachable placement fails closed. This adapter does not derive
production choice gates automatically from the screenplay.

Behavior already implemented and tested:
- Only the actual matching trigger starts the next pending milestone.
- No automatic playback of all scenes.
- Source line effects apply after acknowledged dialogue and durable save.
- Failed line writes re-present the same line.
- Failed choice writes do not publish the branch or effects.
- Multi-selection drafts save independently and survive reload.
- Choice effects apply only after the full distinct selection is confirmed.
- Old callbacks cannot double-confirm a choice or acknowledge a new line.
- Keyboard choice navigation/confirmation is consumed before gameplay input.
- Pointerdown followed by click does not consume a newly opened dialogue line.
- canComplete(sceneId, world) can withhold completion pending a saved battle.
- Failed completion writes show RETRY through the existing UI.
- stop invalidates callbacks while leaving saved progression resumable.
- Completion flags save before onComplete is called.

For production scenes requiring combat, the host MUST explicitly bind
canComplete to the saved mandatory outcome. Its default is permissive; merely
mounting the adapter does not infer encounters from prose.

The adapter is not yet connected to a playable private campaign entry route.
It does not construct private maps, assign actors, stage camera directions,
award prose-described rewards, or provide a finished campaign session host.
